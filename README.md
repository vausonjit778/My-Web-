# PromptBox Website Starter

A responsive static website starter built with HTML, CSS and JavaScript.

## Files
- `index.html` — page structure
- `style.css` — responsive dark theme design
- `script.js` — mobile menu, prompt filters, copy buttons and demo login modal

## Preview locally
Open `index.html` in a browser.

## Deploy with Cloudflare Pages
1. Upload all files and folders in this project to a GitHub repository.
2. In Cloudflare Pages, connect the GitHub repository.
3. For this plain HTML project, choose **Framework preset: None**.
4. Leave **Build command** empty.
5. Set **Build output directory** to `.` (the repository root).
6. Deploy.

## Important
This is a front-end starter/demo. Login, user accounts, paid courses, admin panel, database and bKash/Nagad payments are not connected. They require secure backend services and payment-provider approval before accepting real payments. Do not collect real passwords or payment details with this demo.
